PROCESSING AND REPRODUCTION

scripts/create-radio-voices.py checks the model/config hashes and generates
these original phrases at the model's normal pace (no tempo or pitch change).
Modifications to the synthesized waveform: edge silence/breath trimming with
60 ms consonant padding, 180–3600 Hz filtering, gentle compression, peak
normalization, and mono 24 kHz / 64 kbps MP3 encoding with ffmpeg/libmp3lame.
No added hiss. ONNX Runtime's generation seed is 7. The script checks the
24-second / 200,000-byte voice-only budget before replacing any game assets.
Stage output and run browser audio checks for the overall 64 MiB cache limit.

Developer setup lives outside the repository; see the generator docstring.
Download both pinned model/config URLs above before running the script.
Only the fourteen finished MP3 files ship with the game. No voice model, neural
runtime, Python package, system voice, browser speech service, API key, or
external synthesis service is used by the frontend. Generation runs locally
with ONNX Runtime telemetry disabled.
